🌐 LAYER 2: REST API Server ✅
────────────────────────────────

File: api_server.py
  ✓ Flask-based REST API
  ✓ 10 HTTP endpoints
  ✓ OpenAPI 3.0 schema generation
  ✓ CORS enabled for ChatGPT
  ✓ Response formatting & caching

Commands:
  python api_server.py              # Start on http://localhost:5000
  python api_server.py 8000         # Custom port
  python api_server.py 8000 0.0.0.0 # Custom port & host

Endpoints:
  GET /                              Info & documentation
  GET /health                        Health check
  GET /api/v1/resources              List all resources
  GET /api/v1/resources/{id}         Get resource metadata
  GET /api/v1/resources/{id}/content Get full content
  GET /api/v1/search?q=query         Search resources
  GET /api/v1/resources/category/cat Filter by category
  GET /api/v1/resources/format/fmt   Filter by format
  GET /api/v1/index                  Get lookup index
  GET /api/v1/schema                 Get OpenAPI specification

🤖 LAYER 3b: Claude Integration ✅ (NEW!)
──────────────────────────────────────────

File: claude_client.py
  ✓ Python client for Claude API
  ✓ Tool use integration
  ✓ 6 tools available to Claude
  ✓ Interactive & single-question modes
  ✓ Streaming responses
  ✓ Production-ready error handling

Setup:
  1. pip install -r requirements.txt
  2. export ANTHROPIC_API_KEY="sk-ant-..."
  3. Terminal 1: python api_server.py
  4. Terminal 2: python claude_client.py

Commands:
  python claude_client.py             # Interactive chat
  python claude_client.py -q "...?"   # Single question
  python claude_client.py -v          # Verbose output
  python claude_client.py --api-url   # Custom API URL
  python claude_client.py --model     # Custom Claude model

Make Commands:
  make claude           # Interactive chat
  make claude-q Q="?"   # Ask a question
  make claude-v         # Verbose output

Tools Available to Claude:
  1. list_resources      See all 10 resources
  2. search_resources    Search by keyword
  3. get_resource        Get detailed info
  4. get_by_category     Filter by schema/diagram
  5. get_by_format       Filter by md/pdf
  6. get_index           Get fast lookup index

Benefits:
  ✓ Direct Python integration
  ✓ Real-time tool calling
  ✓ No external tunnel
  ✓ Streaming responses
  ✓ Multi-turn conversations
  ✓ Fine-grained control
  ✓ Production-ready
