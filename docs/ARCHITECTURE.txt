python api_server.py

# Use with Claude

# Or use Make shortcuts
make install       # Install dependencies
make api          # Start API
make claude       # Run Claude client

DEPLOYMENT OPTIONS
═══════════════════

Local Development:
  python api_server.py
  python claude_client.py

ChatGPT (Requires ngrok):
  ngrok http 5000
  (Copy HTTPS URL to ChatGPT custom action)

Cloud Deployment:
  • Railway (recommended)
  • AWS EC2, Lambda, ECS
  • Google Cloud Run
  • Azure Container Instances
  • Heroku

Container Deployment:
  docker build -t mcp-api .
  docker run -p 5000:5000 mcp-api

System Service (Linux):
  systemctl enable mcp-api
  systemctl start mcp-api
