🏗️  THREE-LAYER ARCHITECTURE
─────────────────────────────

Layer 1: MCP Server Core (mcp_server.py)
  ├─ Auto-discovers 10 resources
  ├─ O(1) indexed lookups
  └─ Cached configuration

Layer 2: REST API (api_server.py)
  ├─ 10 HTTP endpoints
  ├─ OpenAPI schema generation
  ├─ CORS for ChatGPT
  └─ Runs on http://localhost:5000

Layer 3: AI Integration
  ├─ ChatGPT Custom Actions (via ngrok)
  │  ├─ Uses OpenAPI schema
  │  ├─ External tunnel required
  │  └─ Public HTTPS URL
  │
  └─ Claude Tool Use (NEW!) ✨
     ├─ Direct Python integration
     ├─ 6 tools available
     └─ Real-time conversation

🚀 QUICK START: CLAUDE
──────────────────────

1. Install dependencies:
   $ pip install -r requirements.txt

2. Set your API key:
   $ export ANTHROPIC_API_KEY="sk-ant-..."

3. Terminal 1 - Start API Server:
   $ python api_server.py
   Listening on http://127.0.0.1:5000

4. Terminal 2 - Chat with Claude:
   $ python claude_client.py

5. Ask questions:
   💬 You: What tables are in the database?
   🤖 Claude: I'll search your resources...

🔧 TOOLS AVAILABLE TO CLAUDE
─────────────────────────────

1. list_resources
   → See all 10 resources with metadata
   → Get category and format info

2. search_resources
   → Search by keyword (e.g., "products")
   → Fast resource discovery

3. get_resource
   → Get detailed resource information
   → Optionally include full content

4. get_by_category
   → Filter by "schema" or "diagram"
   → See resources by type

5. get_by_format
   → Filter by "md" or "pdf"
   → See resources by file format

6. get_index
   → Get fast lookup index
   → See all available resources

💬 USAGE OPTIONS
────────────────

Interactive Chat (Default):
  $ python claude_client.py
  
Single Question:
  $ python claude_client.py -q "What tables are available?"
  
Verbose Output (Debug):
  $ python claude_client.py -v
  
Custom API URL:
  $ python claude_client.py --api-url "http://example.com:5000"
  
Custom Claude Model:
  $ python claude_client.py --model "claude-3-opus-20240229"

Make Commands:
  $ make claude          # Interactive chat
  $ make claude-q Q="?"  # Ask a question
  $ make claude-v        # Verbose output

🎯 RUNNING BOTH CHATGPT AND CLAUDE
──────────────────────────────────

They share the same API and can run simultaneously!

Terminal 1: Start the API Server
  $ python api_server.py

Terminal 2: Expose to ChatGPT (via ngrok)
  $ ngrok http 5000
  Copy HTTPS URL to ChatGPT custom action

Terminal 3: Use with Claude (direct connection)
  $ python claude_client.py

Both ChatGPT and Claude will call the same API!
