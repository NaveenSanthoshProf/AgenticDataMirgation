🚀 QUICK START (3 COMMANDS)
──────────────────────────

1. Install dependencies:
   $ pip install -r requirements.txt

2. Start the API server:
   $ python api_server.py
   OR
   $ bash start.sh

3. Make accessible to ChatGPT:
   $ ngrok http 5000
   (Get URL like: https://xxxxx.ngrok.io)

4. Add to ChatGPT:
   Go to ChatGPT → Explore → Create a GPT → Create new action
   Paste the ngrok URL + /api/v1/schema

🔗 INTEGRATION OPTIONS
──────────────────────

Option 1: ngrok (Fastest, Free)
  • Install ngrok
  • Run: ngrok http 5000
  • Copy HTTPS URL to ChatGPT

Option 2: Cloud Deployment
  • Railway (recommended, free tier)
  • Replit
  • AWS EC2
  • Google Cloud Run
  • Heroku (paid)

Option 3: Docker
  • Build: docker build -t mcp-api .
  • Run: docker run -p 5000:5000 mcp-api

Option 4: Systemd (Linux)
  • Create service file
  • Enable and start
  • Runs automatically on boot

🆘 TROUBLESHOOTING
────────────────────

API won't start?
  → Check port: lsof -i :5000
  → Try different port: python api_server.py 8000

ChatGPT can't connect?
  → Verify ngrok is running and URL is correct
  → Test: curl https://your-ngrok-url/health
  → Check CORS is enabled

Schema validation error?
  → Verify OpenAPI JSON is valid
  → Use https://editor.swagger.io to check
  → Ensure authentication is "None"

Slow responses?
  → Large file (1.6 MB) takes time to transfer
  → Use metadata endpoint first (without ?content=true)
  → Results are cached for performance
